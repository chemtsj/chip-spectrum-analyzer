RSLAB Chip Spectrum Analyzer — v2.0

기존 사이트 업데이트

1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소에서 Streamlit에 연결된 branch(main 등)를 엽니다.
3. Add file > Upload files에서 폴더 안의 아래 7개 파일을 기존 위치에 올립니다.
   app.py가 저장소 첫 화면에 바로 보이는 구조를 유지합니다.

   app.py                       교체: 제목·마이크로칩 아이콘·버튼형 메뉴
   rslab_chip_analysis.py         교체: well별 막대와 오차 계산 추가
   rslab_chip_ui.py               교체: 조건별 업로드·새 화면·내보내기
   rslab_chip_plots.py            새로 추가: 그래프 편집·스택·범례·세 종류의 그림
   requirements.txt              기존과 동일한 Python 의존성 범위
   packages.txt                  기존과 같은 한글 글꼴 설치
   START_HERE.txt                이 설명서

4. 변경 설명에 Update chip analyzer v2를 적고 Commit changes로 저장합니다.
   새 branch라면 main에 병합해야 main에 연결된 사이트가 갱신됩니다.
5. Streamlit이 파일 변경을 감지해 앱을 갱신합니다.
   Main file path=app.py와 기존 사이트 주소를 유지합니다.
6. 화면을 새로고침하고 왼쪽 아래 v2.0 표시를 확인합니다.
   이전 화면이 계속 나오면 Streamlit Manage app에서 Reboot app을 실행합니다.

새 저장소나 새 Streamlit 앱을 만들 필요는 없습니다.
압축을 푼 파일들을 올려야 합니다. 실험 데이터는 사이트에서 업로드합니다.

v2.0 기능

- RSLAB Chip Spectrum Analyzer 제목과 마이크로칩 아이콘.
- 활성 상태가 색으로 표시되는 두 개의 왼쪽 메뉴 버튼.
- 조건 수 지정, 조건별 별도 업로드 창과 조건명 입력.
- 칩 이름은 확인 표에서, 조건 이름은 각 업로드 창에서 편집합니다.
- 같은 조건명으로 입력한 여러 창은 한 조건으로 묶습니다.

'그래프 편집'에서 다음을 설정합니다.
그림 크기·DPI·글꼴·글자 크기·배경, 축 제목·범위·눈금·테두리·격자,
색상 팔레트·곡선별 색상·선 굵기·표시 여부,
수직 스택·자동/지정 간격·개별 오프셋·위아래 반전,
곡선 표시 순서와 범례 순서의 독립 편집, 범례 위치·바깥 배치·열 수·크기.
PNG/PDF/SVG 그래프 다운로드를 제공합니다.

수직 스택 오프셋, 숨김, 축 범위, 표시 순서, 범례 이름은
피크 계산이나 통계 CSV의 intensity를 변경하지 않습니다.
분석 피크 검색 범위는 그래프 X축 범위와 별도로 설정합니다.
전체 결과 ZIP의 processing_manifest.json에 처리·그래프 설정을 기록합니다.

조건별 칩 간 통계 그래프

색깔 점 하나 = well 하나의 대표 스펙트럼 구간 최대값.
검은 점 = 같은 조건의 well 최대값 평균.
검은 오차막대 = 그 well 최대값들 사이의 표본 SD.
같은 조건의 모든 점은 같은 x좌표에 놓습니다.

칩 내·칩 간 편차 한눈에 보기

막대 하나는 well 하나입니다. 같은 조건은 같은 색입니다.
MEAN 모드의 높이는 선택된 파수에서의 mapping 위치별 평균 intensity,
오차막대는 바로 그 파수에서 mapping 위치 간 표본 SD입니다.
검은 점선은 같은 조건의 막대 높이 평균,
조건별 음영은 그 well 값들 사이의 평균±칩 간 SD입니다.
가로선과 음영을 숨겨 well별 막대·오차막대만 볼 수도 있습니다.

막대 값의 두 가지 기준:

1) 각 칩의 구간 최대값 (기본)
   각 chip 대표 스펙트럼에서 지정 구간의 최대값 위치를 찾고,
   그 위치의 intensity와 공간 SD를 사용합니다.
   chip_peak_values.csv의 최대값과 막대 높이가 일치합니다.
   chip마다 피크 파수가 다를 수 있고 실제 파수를 표에 기록합니다.
   이 SD는 위치별 최대값을 따로 찾은 뒤 구한 SD가 아닙니다.

2) 동일 파수에서 비교
   비교 파수를 직접 입력합니다 (예: 측정 범위에 포함된 925 cm^-1).
   각 chip에서 가장 가까운 실제 측정점의 값과 공간 SD를 사용합니다.
   요청 파수, 실제 파수, 차이를 기록하며 보간·외삽하지 않습니다.
   조건별 가로선과 SD 음영도 같은 막대 높이들로 다시 계산합니다.
   기존 구간 최대값 통계와 혼동하지 않습니다.

SUM 모드에서는 높이가 선택 파수에서 mapping intensity를 합한 값입니다.
한 번 구한 SUM에서 반복 SUM의 SD를 직접 측정할 수 없으므로,
독립·동일분포 가정을 켰을 때만 sqrt(N_points)×공간 SD 추정 오차를 표시합니다.
가정이 꺼져 있으면 SUM 막대의 칩 내 오차막대는 표시하지 않습니다.
칩 간 SD는 여러 well의 SUM 값들 사이에서 계산할 수 있습니다.

새 결과 CSV

chip_overview_values.csv:
well별 높이(value), 오차(error), 오차 정의(error_basis),
조건, 비교 방법, 실제 파수, 측정점 수를 저장합니다.

chip_overview_group_statistics.csv:
같은 막대 높이에서 계산한 조건별 well 평균·SD·합을 저장합니다.

전체 ZIP에는 대표 스펙트럼, 조건별 점·오차 그래프, well별 막대그래프 PNG,
기존 통계·mapping CSV, 새 CSV, 처리·그래프 설정이 포함됩니다.
PDF와 SVG는 각 그래프에서 개별 다운로드합니다.

통계 정의

표본 SD는 ddof=1입니다. mapping 위치 간 SD와 독립 well 사이 SD를 구분합니다.
칩 간 평균은 well마다 같은 비중을 주며 mapping 점 수로 가중하지 않습니다.
표본 1개의 SD는 0이 아니라 빈칸입니다.
보정된 mapping CSV는 baseline 없음으로 입력하세요.
Baseline 선택 시 각 위치의 전체 스펙트럼을 먼저 보정한 뒤 평균·합을 구합니다.
대표 스펙트럼에 baseline을 추가 적용하지 않습니다.

로컬 실행 (원할 때만)

Python 3.12 환경에서:
python -m pip install -r requirements.txt
python -m streamlit run app.py
